Ex. 1 – Welford’s Recurrence Formulas

Mathematical Derivation:

Knuth’s update for the mean $\mu_n = \mu_{n-1} + \frac{x_n - \mu_{n-1}}{n}$. Welford's recurrence for the sum of squares $M_2^{(n)} = M_2^{(n-1)} + (x_n - \mu_{n-1})(x_n - \mu_n)$ computes variance efficiently without catastrophic cancellation.

Core JavaScript Implementation:

function welfordVariance(data) { let n = 0, mean = 0, M2 = 0; for (let x of data) { n++; let delta = x - mean; mean += delta / n; M2 += delta * (x - mean); } return { mean, variance: n > 1 ? M2 / (n - 1) : 0 }; }
